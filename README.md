## 先搞清楚：搬瓦工的“三网优化”有三种

搬瓦工官网把三网优化拆成了不同等级的方案，买之前要先分清，因为它们的价格和体验差别不小。

**第一种：CN2 GIA-E 三网优化，主力方案。** 电信方向走 CN2 GIA 专线回程；移动方向走 CMIN2（China Mobile International Network 2）；联通方向走 CUP（China Unicom Premium）。搬瓦工把这条组合线路放在了多个机房，包括洛杉矶 DC6（CT CN2GIA-E + CMIN2 + CUP）、洛杉矶 DC9（CT CN2GIA + CMIN2 + CUP）、圣何塞 SJC5、纽约 USNY_8（Coresite NY1）和温哥华 CABC_6。DC6 和 DC9 是最多人选的两个，晚高峰稳定性在第三方测评里口碑一直不错。

**第二种：单电信 CN2 GIA，港日机房特供。** 香港（Equinix HK2）、大阪、东京（Equinix TY8）这几个机房的套餐，官方标注的路由是“电信 CN2 GIA 直连 + 联通、移动直连”。距离近、延迟低，但流量给得少、价格贵，香港机房还经常缺货。

**第三种：E-Commerce SLA 商务级方案。** 这是搬瓦工较新的产品线，洛杉矶 DC5 机房，NVMe 硬盘，除了 CN2 GIA/CTGNet + 联通 Premium + 移动 CMIN2 三线优化之外，还承诺 99.99% SLA，并且与 Apple、Google、Facebook、字节跳动等网络直连对等互联，每两周可以免费换一次 IP。做外贸建站这种“掉线就是损失”的场景，它比普通 GIA-E 更合适。

一句话总结：日常使用看 DC6/DC9 的 GIA-E，预算充足要低延迟看港日机房，拿 VPS 赚钱的看 SLA 方案。

## 常见问题

**三网优化和普通 CN2 有什么区别？**
普通 CN2 方案（比如 DC2/DC8 机房）电信方向走的是 CN2 GT，也就是电信全球网络，出国段后仍要走普通骨干；GIA 是电信的专用优质线路，从回程一开始就走专线。GIA-E 套餐则在此基础上叠加了移动 CMIN2 和联通 CUP 优化，三家的用户体验都照顾到了。KVM 入门套餐不支持 GIA 机房，这也是它便宜的原因之一。

**联通用户买 GIA-E 划算吗？**
划算，但要知道一个细节：GIA-E 系列的联通方向走 CUP（China Unicom Premium），部分第三方讨论提到联通方向的实测表现有时不及电信方向的 CN2 GIA 稳定，比普通线路仍是明显提升。移动方向 CMIN2 的口碑一直不错。

**1TB 流量够用吗？**
跑个人博客、轻量应用、代理自用，1TB/月比较充裕；跑视频、下载站或多人共享，建议直接看 2TB 以上档位。流量用超会按量计费或限速，年付套餐中途可以在面板升级配置补差价。

**香港机房值得加钱吗？**
看用途。纯追求延迟和访问速度，香港确实是最优解；但如果只是建站和日常使用，DC6/DC9 已经够用，没必要为省几十毫秒多花近六倍的钱。
